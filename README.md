# Automatic-Street-Lighting-System-

1.Project Overview

An intelligent street lighting system designed to improve energy efficiency by automatically controlling streetlight intensity based on vehicle movement.


2.Hardware Components

PIC16F877A Microcontroller

LDR Sensor

IR Sensors

4-Channel Relay Module

LEDs

12v Power Supply 


3.Technologies Used

Arduino Uno

Embedded C/C++ (Arduino programming)

LDR-based light sensing

Four Channel Relay Switching 


4.Working Principle

Normal Mode – 10% Intensity

When the streetlights are activated, they operate at 10% intensity. PWM signals generated by the PIC16F877A are used to control the lighting intensity.

Vehicle Detection Mode – 100% Intensity

When a vehicle is detected by an IR sensor, the system increases the streetlight intensity to 100%, providing improved illumination for road users.
